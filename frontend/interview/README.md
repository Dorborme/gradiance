# Interview Module
This folder contains all front-end pages related to the interview process in the Gradiance Queue and Interview Management System.

## Files
- **student_interview.html** – Provides an interactive chat-style interface for students during the interview session. Students can view instructor messages, reply, and submit answers.
- **instructor_interview.html** – Allows instructors to conduct interviews, send questions, broadcast follow-up prompts, and take notes (potentially integrated with Google Forms).

## Purpose
These pages aim to create a smooth real-time interaction between students and instructors. The layout emphasizes clarity, accessibility, and easy communication flow.

## Integration Notes
- The interface will connect to the back-end through WebSocket or REST APIs.
- The instructor interface supports question broadcasting and logging of interview notes.
- The student interface focuses on readability and fast response input.
