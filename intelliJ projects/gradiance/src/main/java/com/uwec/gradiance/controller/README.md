# CONTENTS

this subdirectory contains java classes and methods that perform various functions based on the url endpoint defined for that function.

# PURPOSE

these classes allow the Gradiance frontend to make REST API calls the Gradience backend. This enables more complex and powerful interaction between clients and the backend and database.

    - Java Spring Framework: https://docs.spring.io/spring-framework/docs/6.2.11/javadoc-api/
