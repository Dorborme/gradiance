# CONTENTS

This subdirectory contains files related to the data access object (DAO) that controls the entities defined in the database folder. Essentially, the DAO contains the EntityManager and all functionality associated with that feature.


# PURPOSE

These classes define how entities are managed including how they are saved to the EntityManager, created, queried for, and deleted.


# DEPENDENCIES

- Jakarta Persistence: https://jakarta.ee/learn/docs/jakartaee-tutorial/current/persist/persistence-intro/persistence-intro.html
